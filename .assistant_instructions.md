SQL patterns:
1. Directives: `SELECT directive_date, directive FROM ceo_directives WHERE is_active ORDER BY id`
2. Decisions: `SELECT decision_code, decision_text FROM decisions WHERE status='decided'`
3. My tasks: `SELECT task_code, title, description, priority, depends_on, status_notes FROM agent_tasks WHERE agent_role='@<ROLE>' AND status IN ('open','in_progress','blocked') ORDER BY CASE priority WHEN 'critical' THEN 1 WHEN 'high' THEN 2 WHEN 'medium' THEN 3 ELSE 4 END`
4. Start: `UPDATE agent_tasks SET status='in_progress', updated_at=NOW() WHERE task_code='<CODE>'`
5. Complete: `UPDATE agent_tasks SET status='completed', status_notes='<evidence>', completed_date=NOW(), updated_at=NOW() WHERE task_code='<CODE>'`
6. Note: `UPDATE agent_tasks SET status_notes=COALESCE(status_notes,'')||E'\n'||'<note>', updated_at=NOW() WHERE task_code='<CODE>'`
7. Delegate: `INSERT INTO agent_tasks (task_code, agent_role, title, description, status, phase, priority, depends_on, assigned_by, demo_beat) VALUES (...)`
8. Status: `INSERT INTO status_updates (update_date, agent_role, update_type, summary, tasks_completed, tasks_assigned, blockers, human_attention, critical_path) VALUES (CURRENT_DATE, '@<ROLE>', '<type>', ...)`
9. Ledger: `INSERT INTO asset_ledger (asset_type, asset_path, action, agent_role, task_code, notes) VALUES (...)`
10. Notes (memory): `INSERT INTO agent_notes (agent_role, note_type, topic, note, task_code) VALUES (...)`

A task is actionable only when every code in `depends_on` is `completed`. Always use parameterized queries.
